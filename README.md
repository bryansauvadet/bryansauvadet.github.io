## Convention éditoriale — noms de personnes

Dans le texte courant du site, ne jamais désigner une personne uniquement par son nom de famille. Toujours employer son nom complet, prénom(s) + nom de famille (par exemple : « Shih-shan Susan Huang », « Richard D. McBride, II »). Les formes bibliographiques normalisées peuvent conserver leur ordre propre dans les références bibliographiques.

## Convention éditoriale — royaumes coréens

Dans le texte français, employer systématiquement l’article défini avec les noms des royaumes et dynasties coréens : « le Silla », « le Paekche », « le Koguryŏ », « le Koryŏ » et « le Chosŏn ». Employer donc les formes contractées « du Silla / du Paekche / du Koguryŏ / du Koryŏ / du Chosŏn » et « au Silla / au Paekche / au Koguryŏ / au Koryŏ / au Chosŏn ». Conserver la romanisation McCune–Reischauer.
