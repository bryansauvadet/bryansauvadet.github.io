## Convention éditoriale — noms de personnes

Dans le texte courant du site, ne jamais désigner une personne uniquement par son nom de famille. Toujours employer son nom complet, prénom(s) + nom de famille (par exemple : « Shih-shan Susan Huang », « Richard D. McBride, II »). Les formes bibliographiques normalisées peuvent conserver leur ordre propre dans les références bibliographiques.
